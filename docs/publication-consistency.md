# 記事保存と公開データの整合性

## 保存の契約

- 下書きは自動保存できます。公開中の記事への自動保存は管理画面で停止し、APIも HTTP 409 で拒否します。公開中の変更は「保存」で確定します。
- 手動保存は実行中の自動保存を待ち、同時送信を防ぎます。保存失敗時には未保存状態を維持します。
- 更新は取得時の `version` を送信します。DynamoDB の条件付き書込みで競合を検出し、HTTP 409 を返します。競合時は入力を退避して再読込みし、最新内容と比較してください。
- 既存の `version` がない記事は version 0 として扱います。最初の更新で 1 になり、以後は最新の version が必須です。
- `excerpt` と `coverImageUrl` は空文字で消去できます。省略は既存値の維持を意味します。
- slug の確保と記事更新は同一トランザクションです。予約項目 `SLUG#<slug>` は GSI キーを持たず、記事一覧に入りません。slug 変更・記事削除では所有者条件付きで予約を解放します。
- 既存記事の slug 検索は引き続き GSI を使います。既存データの重複を自動修復する変更ではありません。バックフィルも記事の条件付き更新と予約を同一トランザクションで行います。
- 記事削除の条件付き書込みが失敗した場合、画像は削除しません。記事削除後の画像清掃失敗は警告ログに記録して HTTP 204 を返します。残存画像の清掃は別途必要です。

## 公開サイトと配信

- 一覧 API が slug・抜粋・カバー画像を返し、Astro が利用します。slug URL に加えて従来の ID URL も生成し、canonical は slug URL に統一します。記事間のパス重複はビルド失敗として検出します。
- CloudFront の公開サイト用関数は、閲覧者からの `/releases` 配下への直接アクセスを 404 で拒否します。内部の有効リビジョンへの書換えは継続します。
- 有効な公開リビジョンの削除を防ぐため、公開リリースの現行オブジェクトを日数だけで期限切れにする Lifecycle ルールを廃止します。過去リリースも保持されるため、容量は増加します。有効リビジョンとロールバック対象を保護する清掃処理は別途必要です。
- 存在しない公開オブジェクトを S3 が 404 で返せるよう、公開サイトバケットだけに `s3:ListBucket` を追加します。Principal は CloudFront サービス、SourceArn は対象ディストリビューションに限定します。バケット一覧を取得できる権限の追加であるため、公開ルーティングがバケットルートや任意のクエリをオリジンへ転送しない前提を維持してください。API の 403 を一律 404 に置換する設定ではありません。

## 反映時の留意事項

この変更をローカルで検証しても稼働環境には反映されません。API と管理画面を同じリリースとして反映し、開いている編集画面を再読込みしてください。古い書込み実装と新しい実装が混在する移行期間は、記事編集を停止すると安全です。既存リリースの削除やデータバックフィルはこの変更だけでは実行されません。

Terraform 反映後は、通常の記事 URL、存在しない URL、旧リリースの直接 URL、および API の認証エラーを実環境で確認してください。モックテストでは AWS 側の実際の権限や CloudFront への反映完了までは検証できません。

## 設計の参照元

- [AWS S3 GetObject API](https://docs.aws.amazon.com/AmazonS3/latest/API/API_GetObject.html): `s3:ListBucket` の有無による存在しないオブジェクトの 404 / 403 の違い。
- [AWS CloudFront OAC](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/private-content-restricting-access-to-s3.html): SourceArn を使ったディストリビューション限定のバケットポリシー。
- [AWS S3 Lifecycle expiration](https://docs.aws.amazon.com/AmazonS3/latest/userguide/lifecycle-expire-general-considerations.html): 日数ベースの期限切れ動作。

上記は AWS の一次資料です。保存・競合制御の仕様は、このリポジトリの実装と回帰テストに基づきます。
